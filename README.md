# Raksha

**A women's emergency-assistance prototype built in 24 hours at the SRM–ACM Hackathon.**

Raksha explored how to make it easier to ask for help in an emergency. The project won at the SRM–ACM Hackathon, which was supported by Microsoft Azure.

| | |
| --- | --- |
| **Project** | Women's emergency assistance |
| **Built at** | SRM–ACM Hackathon |
| **Build time** | 24 hours |
| **Result** | Hackathon winner |

This repository currently contains the project overview. Raksha is a hackathon prototype. For an active emergency, use your local emergency services.
